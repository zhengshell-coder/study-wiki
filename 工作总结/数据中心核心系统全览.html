[01] 数据中心基础设施分层模型

数据中心基础设施（DCI）是支撑 IT 负载稳定运行的所有物理系统的总称。自底向上可分为五层，每一层为上层提供服务保障：

L5 · IT 设备层

L3 · 暖通系统
精密空调 冷水机组 冷却塔 通道封闭 液冷
L2 · 供电系统
市电引入 变压器 UPS 蓄电池 PDU 柴油发电机
L1 · 物理设施层
建筑结构 楼板承重 防雷接地 防水防尘 消防隔断

[02] Uptime Institute Tier 等级标准

国际通行的数据中心可靠性分级标准，从 Tier I 到 Tier IV，可用性逐级提升：

等级 可用性 冗余配置 容错能力 适用场景
Tier I 99.671% 单路供电（N） 无冗余，计划维护需停机 小型企业 / 非核心业务
Tier II 99.741% 部分冗余（N+1） 单路供电+部分组件冗余 中型企业 / 一般业务
Tier III 99.982% 双路供电（可并行维护） 支持在线维护，不停机 大型企业 / 核心业务
Tier IV 99.995% 完全冗余（2N / 2N+1） 单点故障容错，零中断 金融 / 超大规模云 / 关键任务
关键概念

N = 满足负载所需的基本容量；N+1 = 1 个备份模块；2N = 两套完全独立的系统互为备份；2N+1 = 两套系统各有额外备份模块。

[04] 中国国家标准 GB 50174《数据中心设计规范》

除 Uptime Tier 国际标准外，中国数据中心建设还须遵循GB 50174（2017 版），该规范将数据中心分为 A/B/C 三级，与 Uptime Tier 大致对应但存在差异：

GB 50174 等级对应 Uptime Tier容错要求关键设计指标
A 级 ≈ Tier IV 容错（2N+1） 供电 2N / 制冷 N+1 或 2N / 不得停电
B 级 ≈ Tier III 冗余（N+1） 供电 N+1 / 制冷 N+1 / 可在线维护
C 级 ≈ Tier I/II 基本（N） 供电单路 / 基本配置
GB 50174 关键设计指标摘录

① 机房温湿度（A级）：18~27°C / 40~60% RH（冷通道）；② 防静电地板：架空高度 ≥ 300mm，承重 ≥ 10kN/㎡；③ 噪声：主机房 ≤ 80dB（有人值守时 ≤ 70dB）；④ 照度：主机房 ≥ 500lx；⑤ 接地：综合接地 ≤ 1Ω；⑥ 防火：耐火等级不低于二级，设气体灭火。

发电机应急逻辑

市电停电 → ATS 检测断电（<10ms）→ 发出启动信号 → 柴油发电机启动（15~30s 达额定频率/电压）→ ATS 切换至发电机侧 → UPS 电池桥接切换间隙 → 持续供电至市电恢复。

UPS 内部拓扑与工作模式
在线双变换 主模式
  • 市电 → 整流器 → 逆变器 → 负载
  • 完全隔离市电干扰
  • 输出纯净正弦波
  • 效率约 94%~97%
  • 电池始终在线并联
静态旁路 旁路
  • UPS 故障/过载时自动切换
  • 市电直接供给负载
  • 切换时间 < 4ms
  • 由静态开关（SCR）实现
  • 负载不感知中断
维修旁路 手动
  • 人工操作机械开关
  • 完全绕过 UPS 内部
  • 用于 UPS 维护/更换
  • 切换过程需先合后断
  • 保证维护期间不停电

[04] 冷板式液冷

通过安装在 CPU/GPU 等高功耗芯片上的铜质冷板，利用导热液（通常是 25°C 左右的温水）将热量带走。

  • 冷却液不直接接触电子元件
  • 水温 25~40°C，水温高于室温
  • 可带走芯片 70%+ 热量，剩余由风冷补充
  • 改造门槛较低，兼容现有服务器架构
  • 冷却液：纯水 / 乙二醇水溶液 / 超纯水

[05] 浸没式液冷

将整个服务器完全浸没在绝缘冷却液中，通过液体直接接触所有发热元件进行散热。

  • 冷却液为不导电氟化液或矿物油
  • 散热效率最高，PUE 可达 1.1 以下
  • 无需风扇，噪音为零
  • 分为单相（不沸腾）和两相（相变换热）
  • 改造成本高，运维复杂度高

为什么走向直流化？

GPU 服务器内部本质上使用低压直流（12V/48V）。传统 AC 供电需经历 AC->AC（变压器）-> AC->DC（UPS 整流）-> DC->AC（UPS 逆变）-> AC->DC（服务器 PSU）共 4 级转换，每一级损耗 2~3%。HVDC 直接将市电整流为高压直流，经 UPS 直流母线 + 一次 DC-DC 降压到机柜，转换级数减半，端到端效率提升 3~5%。

[01] 液冷崛起：为什么变得如此重要

液冷从"可选优化"变为"必选基座"，背后是五重驱动力同时叠加，形成不可逆的产业趋势：

物理极限的铁律

空气比热容仅 1.0 kJ/(kg·K)，水的比热容是空气的 4 倍，导热系数是空气的 24 倍。当单柜超过 30kW，风冷需要的风量和风速会产生气流噪声、局部涡流、旁路气流等一系列问题，工程上已不可行。这不是"液冷更好"的问题，而是"风冷做不到"的问题。

范式差异的本质

风冷建设以"气流组织"为核心--设计冷热通道、计算风量、选配空调。液冷建设以"流体管理"为核心--设计管路拓扑、计算流量/压损、选配 CDU、防控漏液。这是从空气工程到流体工程的专业跨越，建设团队需要引入暖通管路工程师和液冷专项运维人员。

管路设计关键参数

流量计算：Q = P / (c × ΔT)，其中 P 为热量(kW)、c 为比热容(kJ/kg·K)、ΔT 为供回水温差(°C)。典型 100kW 柜、ΔT=10°C 时流量约 2.4 m³/h。管径选型：流速控制在 0.5~1.5 m/s，过大产生噪声和压损，过小导致管径过大。压损控制：二次侧总压损 ≤ 0.3 MPa，CDU 水泵扬程需覆盖管路+冷板+Manifold 总阻力。

[04] 要点 2：高水温策略与自然冷却协同

液冷最核心的能效杠杆不是"液冷替代风冷"本身，而是高进水温度带来的全年自然冷却能力。这是液冷 PUE 能降至 1.1 的根本原因：

为什么水温可以这么高？

冷板液冷的冷板直接贴在芯片表面，热阻极低（~0.01 K/W），即使进水 40°C，芯片结温也能控制在 85°C 以下（安全阈值 ~95°C）。而风冷需要空气先经过散热鳍片再带走热量，热阻链路长，必须维持较低的冷通道温度（18~22°C）才能保证芯片不降频。高水温 = 压缩机关停 = PUE 逼近 1.0。

[05] 要点 3：防漏体系 -- 三重防护设计

漏液是液冷建设最被关注的风险。成熟的液冷 DC 采用"预防-检测-应急"三重防护体系，使漏液概率和影响降至极低：

L1 · 预防层
盲插快接头（UDC/QD3） 双道密封圈 管路压力监测 EPDM 防腐软管 出厂保压测试 管路色标管理
L2 · 检测层
漏水检测绳（定位 ±1m） 液位传感器 流量差监测（供-回差） 湿度异常报警 DCIM 实时联动
L3 · 应急层
应急关断阀（自动切断） 防漏堰（拦截漫流） 地漏+排水沟 声光报警+短信通知 UPS 不间断水泵 应急预案演练
漏液场景与处置流程

场景：快插接头密封老化 -> 微量渗漏 -> 漏水检测绳触发 -> DCIM 报警 -> 应急关断阀自动关闭该支路 -> CDU 切换至备用回路 -> 维修人员到场更换接头 -> 恢复供液。全程 IT 负载不中断（冷板热容 + 风冷辅助可维持 3~5 分钟过渡）。
