一句话认识微积分In One Line

微积分是研究连续变化的数学语言。它用两把钥匙打开了理解世界的大门：导数描述"此刻变化有多快"，积分描述"一点点累积起来是多少"。

如果你还记得高中物理里"位移求导得速度，速度求导得加速度"——恭喜，你已经懂了微积分的核心直觉。现在我们要做的，只是把这份直觉重新激活、补全、然后用到真实世界中去。

微积分的两根支柱
微分 · Derivative"切片"

把一段连续的变化，切成无限薄的瞬间，去看每个瞬间的"变化率"。

  • 核心问题：此刻的速度是多少？
  • 几何直觉：曲线在某点的切线斜率
  • 记号：f'(x) 或 dy/dx
  • 回答的是："快不快"、"往哪走"
积分 · Integral"拼接"

把无限多个瞬间的微小量，拼接累积成一个整体。

  • 核心问题：总共积累了多少？
  • 几何直觉：曲线下方的面积
  • 记号：∫f(x)dx
  • 回答的是："总共多少"、"积了多少"
为什么微积分如此重要Why It Matters

世界不是静止的——行星在转、股价在变、信号在传、神经在放电。任何涉及"连续变化"的问题，背后的语言都是微积分。

物理靠它描述运动，通信靠它分解信号，AI靠它优化学习。微积分不是一门"考完就忘"的课，而是理解现代世界运行规律的底层语法。
如果你曾经觉得微积分"学过但没真正懂"，那大概率是因为当初只学了公式、没理解直觉。这篇文章的目标，就是帮你把直觉找回来。

牛顿的突破Newton

牛顿的关键洞察：运动可以看作位置随时间"流动"。他引入"流数"（即导数）来描述流动的快慢，又发现反过来"积分"可以还原流动的总量。

更关键的是——他意识到求导和积分互为逆运算。这意味着切线问题和面积问题，其实是同一个问题的两个面。

莱布尼茨的贡献Leibniz

莱布尼茨独立得到同样结论，但他更大的贡献是符号。他发明的 dy/dx 直观地表达了"变化量之比"，∫（拉长的 S）代表"求和"。

这些符号太好用了，至今全世界还在用。我们今天学的微积分符号体系，几乎全部来自莱布尼茨。

核心突破：两个难题是一个问题The Breakthrough

在牛顿和莱布尼茨之前，"求切线"和"求面积"是两个互不相干的难题，各搞各的。他们的突破在于发现：求导（微分）和积分互为逆运算——就像加法和减法、乘法和除法一样。

这个发现被称为"微积分基本定理"。它把两千年的两条路打通成了一条，微积分从此正式诞生。
牛顿是怎么发现微积分的Newton's Path

牛顿不是为了发明数学而发明数学。他是在研究行星为什么按椭圆轨道运动时，被逼着发明了微积分。下面还原他的完整思路链。

① 起点：一个没有工具的问题The Problem

开普勒已发现行星沿椭圆轨道运行（1609），但为什么？什么力在驱动？牛顿猜测：太阳对行星有引力，且引力随距离减弱。但要验证这个猜想，他需要计算"连续变化的速度和位置"--当时的数学工具做不到。

具体来说，他面临三个子问题：

  • 行星每一瞬间的速度方向是什么？（切线问题）
  • 速度每时每刻都在变，变化率是多少？（加速度问题）
  • 如果引力 F ∝ 1r²，轨道方程是什么？（微分方程）
牛顿需要一个能处理"连续变化"的数学。既然没有，他就自己造一个。
② 流数：把世界看作"流动"Fluents & Fluxions

牛顿的核心洞察：所有物理量都在"流动"--时间在流、位置在流、速度在流。他把随时间变化的量叫"流数"（fluent），把变化率叫"流数率"（fluxion）。

用今天的记号：如果 x(t) 是位置（流数），那么 ẋ = dxdt 就是速度（流数率）。牛顿在变量上面点一个点表示流数率：ẋ = 导数，ẍ = 二阶导数。这个记号物理学家至今还在用。

牛顿的记号   ->   今天的记号
ẋ   =   dxdt   =   f'(t)   (一阶导数 / 速度)
ẍ   =   d²xdt²   =   f''(t)   (二阶导数 / 加速度)
③ 关键洞察：切线 = 瞬时运动方向Tangent = Motion

牛顿做了一件前人没做过的事：他把几何问题翻译成了运动问题。想象一个点沿曲线 y = f(x) 运动，它在每个瞬间的运动方向，就是曲线在该点的切线方向。

求切线 = 几何问题画一条只触碰曲线一点的线
›
求切线 = 运动问题求运动质点的瞬时方向

这一步把"求切线"和"求瞬时速度"统一成了同一个问题。两个困扰数学界上千年的难题，在牛顿的运动视角下合二为一。

④ 牛顿的求导方法：小增量逼近Newton's Method

牛顿的具体做法：给变量 x 一个微小增量 o（他的记号），看函数值变化多少，然后让增量"消失"。以 y = x² 为例，完整推导：

目标：求 y = x² 在任意点的变化率（导数）

第一步：给 x 一个微小增量 o
    新的 y 值 = (x + o)² = x² + 2xo + o²

第二步：算 y 的变化量
    Δy = (x² + 2xo + o²) - x² = 2xo + o²

第三步：算变化率（变化量 ÷ 增量）
    Δyo = 2xo + o²o = 2x + o

第四步：让增量 o "消失"（取极限 o -> 0）
    变化率 = 2x + 0 = 2x ✓

结果：y = x² 的导数是 2x。这就是幂法则 ddx[xⁿ] = n·xⁿ⁻¹ 在 n=2 时的特例。牛顿对各种函数重复这个过程，总结出了通用规律。

注意第四步：o "消失"但不是"等于零"。这正是后来贝克莱批评的地方--o 到底是不是零？这个问题等了 150 年才被柯西和魏尔斯特拉斯解决（见第 3 章）。
⑤ 最大的发现：求导和积分互为逆运算The Inverse Discovery

牛顿在算变化率的过程中，注意到一个深刻的关系：如果你知道变化率，可以反推回原函数。就像你知道加速度，可以积分出速度，再积分出位置。

正向（求导）：位置 s(t) -> 速度 v(t) = s'(t) -> 加速度 a(t) = v'(t)
逆向（积分）：加速度 a(t) -> 速度 v(t) = ∫a(t)dt -> 位置 s(t) = ∫v(t)dt

这意味着："求面积"（积分）和"求变化率"（求导）是同一件事的两个方向。这就是微积分基本定理--牛顿最重要的发现。

在牛顿之前，"求切线"的人不知道"求面积"的人在干嘛，反过来也一样。牛顿发现它们互为逆运算后，两千年来的两条路终于打通成了一条。
⑥ 从引力到轨道：微积分的终极验证From Gravity to Orbits

有了微积分，牛顿终于可以做一件震撼世界的事：只凭一条假设（引力与距离平方成反比），从数学上推出开普勒的全部三条定律。开普勒的定律是"看出来的"（二十年观测数据的总结），牛顿的推导是"算出来的"（从一条物理定律出发的必然结论）。

这段推导被誉为牛顿推理能力的巅峰，也是微积分第一次在重大科学问题上的完整实战。下面把推导拆成四步，每一步都给出完整的数学过程。

第一步：把引力写成运动微分方程Step 1 · The Equation

把两条定律合并：万有引力 F = GMmr²（G 为引力常数，M 为太阳质量，m 为行星质量，r 为距离），加上牛顿第二定律 F = ma。注意力的方向永远指向太阳（径向），所以行星的运动方程是：

m·a = -GMmr²   →   a = -GMr²   (负号 = 加速度指向太阳)
第一步 · 前置知识：什么是极坐标？Polar Coordinates 101

要描述行星的位置，首先得选一套"坐标系"。最常见的有两种，它们用完全不同的方式定位同一个点：

直角坐标 (x, y)Cartesian

从原点出发，向右走 x 步，再向上走 y 步，就到了目标点。像城市网格--"东三环北四路"。

  • 两个量：x（横向距离）、y（纵向距离）
  • 单位向量 î、ĵ 永远固定，不随位置变化
  • 适合：网格、屏幕像素、建筑图纸
  • 引力 F = GMm/r² 拆成 Fx、Fy 很麻烦
极坐标 (r, θ)Polar

从原点出发，沿着角度 θ 的方向，走 r 步，就到了目标点。像雷达扫描--"距离 10 公里，方位 45°"。

  • 两个量：r（到原点的距离）、θ（从参考方向转过的角度）
  • 单位向量 êr、êθ 随位置旋转
  • 适合：轨道、雷达、波纹、万有引力
  • 引力 F = GMm/r² 里只有 r，天然匹配

两种坐标描述的是同一个点，可以互相转换--这就是三角函数的本质：

x = r · cos θ     y = r · sin θ     r = √(x² + y²)     θ = arctan(y/x)
极坐标不是为了为难你，而是为了让方程更简单。引力只依赖距离 r，不依赖角度 θ--用极坐标，这个物理事实直接反映在方程里。用直角坐标的话，x 和 y 相互耦合，方程会复杂得多。
第一步 · 铺垫：位置在极坐标下怎么写Position in Polar

在直角坐标里，位置写成 (x, y)，两个单位向量 î、ĵ 是固定的--永远指向同一个方向。但行星绕太阳运动，用极坐标更自然：用距离 r（到太阳多远）和角度 θ（转了多少度）来确定位置。

位置向量   =   r · êr    (长度为 r，方向为 ê_r)

这里有个容易忽略的关键点：êr 不是固定的！它是"从太阳指向行星"的单位向量，行星转到哪里，它就指向哪里。还有一个配套的 êθ --垂直于 êr，指向角度增大的方向。这两个单位向量随着行星的运动而旋转。

在直角坐标里，单位向量 î、ĵ 是"死的"（永远不动）。在极坐标里，êr、êθ 是"活的"（跟着行星转）。这个区别就是后面所有"多出来的项"的根源。
第一步 · 第一层：速度 = 位置求导（乘积法则！）Velocity

速度是位置的导数：v = d/dt [位置]。位置 = r·êr，这是两个都在变的东西相乘--r 在变（距离在变），êr 也在变（方向在转）。所以必须用乘积法则：

v = ddt [ r · êr ]

= drdt · êr   +   r · d(êr)dt

(乘积法则：第一个求导 × 第二个不动 + 第一个不动 × 第二个求导)

第一项 r'·êr 没问题。但第二项里的 d(êr)/dt 是什么？ êr 是一个单位向量，它的长度不变（永远是 1），但它的方向在变。当角度 θ 增加一点点 dθ 时，êr 转了 dθ --它的变化量 dêr 指向垂直于 êr 的方向，也就是 êθ 的方向：

单位向量的求导法则（极坐标专属）：

  d(êr)dt = dθdt · êθ    (ê_r 的导数 = 角速度 × ê_θ)
  d(êθ)dt = -dθdt · êr    (ê_θ 的导数 = -角速度 × ê_r，注意负号)

把这个结果代回去，速度就有两项了：

v = drdt · êr   +   r · dθdt · êθ

径向速度（靠近/远离太阳） + 切向速度（绕太阳转）
在直角坐标里，速度只有 x' 和 y' 两个简单项。在极坐标里，速度分成了径向（r'，距离变化）和切向（r·θ'，旋转变化）两部分。多出来的 θ' 和 r，都来自单位向量在旋转这个事实。
第一步 · 第二层：加速度 = 速度再求导（四项变两项）Acceleration

加速度是速度的导数。速度 v = r'·êr + r·θ'·êθ 有两项，每项都是"标量 × 旋转向量"的乘积。对每一项用乘积法则，再代入单位向量的求导法则，展开后一共四项：

a = ddt [ r'·êr + r·θ'·êθ ]

第一项：d/dt [r'·êr] = r''·êr + r'·(θ'·êθ)   (乘积法则 + ê_r' = θ'·ê_θ)

第二项：d/dt [r·θ'·êθ] = r'·θ'·êθ + r·θ''·êθ + r·θ'·(-θ'·êr)   (乘积法则 + ê_θ' = -θ'·ê_r)

四项加起来，把 êr 和 êθ 分别合并：

  含 êr 的：  r'' - r·(θ')²    (两项合并，一个来自第一项，一个来自第二项的红色部分)
  含 êθ 的：  r'·θ' + r·θ'' + r'·θ' = r·θ'' + 2·r'·θ'    (三项合并，两个 r'·θ' 来自不同地方)

最终，加速度在极坐标下的完整表达式：

a = [ d²rdt² - r·(dθdt)² ] · êr   +   [ r·d²θdt² + 2·drdt·dθdt ] · êθ

径向分量（沿 ê_r） + 切向分量（沿 ê_θ）
第一步 · 第三层：为什么"多出来"两项？Why Extra Terms?

在直角坐标里，加速度就是 a = x''·î + y''·ĵ --干干净净，没有多余的东西。为什么极坐标下会多出 -r·(θ')² 和 2·r'·θ' 这两项？因为坐标系本身在转。

-r·(θ')²：向心项Centripetal

即使 r 不变（完美的圆轨道），行星也有径向加速度！为什么？因为速度方向在不停偏转--行星每时每刻都在"转弯"。转弯就是加速度，哪怕距离没变。

这就像你开车转圈--速度大小不变，但方向盘一直在转，你被"甩"向外侧。这个力就是向心力 = m·r·(θ')²，方向指向圆心（太阳）。

2·r'·θ'：科里奥利项Coriolis

即使角速度 θ' 恒定（匀速旋转），只要 r 在变（行星靠近或远离太阳），就有切向加速度！为什么？因为"越靠近中心，同样的角速度对应的线速度越小"。

想象花样滑冰旋转时收回手臂--角速度会变快。反过来，手臂伸出去时会变慢。这种 r 变化引起的切向效应，就是 2·r'·θ'。

直角坐标的 î、ĵ 是"死的" -- 求导为零，不产生多余项。极坐标的 êr、êθ 是"活的" -- 求导不为零，每求一次导就"冒出"新项。这就是极坐标比直角坐标复杂、但也更适合描述旋转运动的原因。
第一步 · 终点：代入引力，得到两条方程The Two Equations

现在把加速度的完整表达式和引力对接。引力 F = -GMm/r² · êr，只有径向分量，切向为零（引力始终指向太阳，不会"拧"行星）。代入 F = ma：

径向（引力 ≠ 0）：  m · [ d²rdt² - r·(dθdt)² ] = -GMmr²

切向（引力 = 0）：  m · [ r·d²θdt² + 2·drdt·dθdt ] = 0

两边约掉 m（质量不影响运动！这就是等效原理的萌芽），得到最终方程组：

径向：  d²rdt² - r·(dθdt)² = -GMr²   (引力拉行星靠近太阳)

切向：  r·d²θdt² + 2·drdt·dθdt = 0   (无力矩 -> 角动量守恒)
这就是牛顿要解的微分方程组：两个未知函数 r(t)、θ(t)，两条方程。径向方程描述"引力如何拉扯距离"，切向方程描述"无力矩时旋转如何守恒"。后续三步，就是在解这组方程。
第二步：切向方程 → 开普勒第二定律（等面积）Step 2 · Equal Areas

先解比较容易的切向方程。关键技巧：把整个方程乘上 r（这正好是乘积法则的"反用"）：

原方程：  r·θ'' + 2·r'·θ' = 0

两边乘 r：  r²·θ'' + 2·r·r'·θ' = 0

识别出乘积法则：  ddt [ r²·dθdt ] = 0

积分：  r²·dθdt = h   (h 为常数——积分一次的结果)

r²·θ' = 常数 的物理含义：角动量守恒（角动量 L = m·r²·θ'）。为什么守恒？因为引力始终指向太阳，对行星产生的力矩（r × F）恒为零——力没有"拧动"行星旋转的能力。

现在把这个常数翻译成几何语言。行星在一小段时间 dt 内扫过的面积（扇形）：

面积速率   dAdt = ½·r²·dθdt = h2 = 常数
结论：行星单位时间扫过的面积处处相等——这就是开普勒第二定律 ✓。开普勒用 10 年苦算得到的规律，牛顿只花了两行积分。
第三步：径向方程 → 椭圆轨道（开普勒第一定律）Step 3 · The Ellipse

现在攻最难的一关。径向方程 d²rdt² - r·(dθdt)² = -GMr² 直接解不动——它包含 r 和 θ 的耦合。牛顿的办法（现代教科书称为 Binet 换元）：

引入新未知数 u = 1/r，并利用上一步的常数 h = r²·θ'，把方程里所有 r 的导数换成对 θ 的导数：

换元关系（三个都能由 u = 1/r 和 r²θ' = h 推出来）：

  ①  dθdt = h·u²
  ②  drdt = -h·dudθ
  ③  d²rdt² = -h²u²·d²udθ²

代入径向方程，两边除以 -h²u²：

  d²udθ² + u = GMh²   (常数！)

惊喜出现了：换元后方程变成了简谐振子方程——和第 7 章弹簧振动 x'' = -ω²x 完全同型！它的解是：

u = GMh²·(1 + e·cos θ)   →   还原 r = 1u：

r(θ) = p1 + e·cos θ   其中 p = h²GM，e 是积分常数（离心率）

最后识别形状。这是圆锥曲线的极坐标方程：

  • e = 0：圆轨道
  • 0 < e < 1：椭圆轨道 ✓ —— 开普勒第一定律
  • e = 1：抛物线（一去不回）
  • e > 1：双曲线（掠过太阳的彗星）
核心洞察："把 1/r 当作未知数"之后，行星绕太阳的引力问题，数学上就变成了弹簧振动问题——同一个方程，串起了弹簧、钟摆和整个太阳系。
第四步：椭圆几何 → 开普勒第三定律（T² ∝ a³）Step 4 · The Period Law

第三定律说的是"行星公转周期 T 的平方与轨道半长轴 a 的立方成正比"。它藏在第二步的面积速率和椭圆的几何里：

①   面积速率 dAdt = h2，一周期 T 内扫过整个椭圆面积 πab（a 半长轴、b 半短轴）：
    T·h2 = πab  →  T = 2πabh

②   椭圆几何关系：b² = a²(1 - e²)，而由 p = h²GM 得：
    b² = a·p = a·h²GM

③   把 b² 代入并整理：
    T² = 4π²a²b²h² = 4π²·a²·a·h²GM·h² = 4π²a³GM ✓

结论：T² = 4π²GM·a³。括号里只含太阳的常数，所以对同一太阳的所有行星，T²a³ = 同一个值——开普勒第三定律 ✓。

至此，微积分从一条引力假设出发，把开普勒的三条定律全部"证明"了出来——观测事实从此变成了数学必然。

极限：一切的起点The Foundation

导数和积分都建立在一个概念上——极限。不弄懂极限，微积分就是一堆没有灵魂的公式。好消息是，极限的直觉非常简单。

从芝诺悖论说起Zeno's Paradox

古希腊的芝诺提了一个悖论：阿基里斯追乌龟，每次到达乌龟上一个位置时，乌龟又往前走了一点点。如此无限循环——阿基里斯永远追不上乌龟？

我们当然知道阿基里斯能追上。问题出在哪？无限个越来越小的步骤，加起来可以是一个有限的数。这就是极限的核心思想：无限逼近，但结果有限。

极限不是"到达"，而是"无限接近"。它问的不是"等于多少"，而是"趋近于多少"。
可视化：一个经典极限

看这个函数：f(x) = (x² - 1) / (x - 1)。当 x = 1 时，分母为零，函数"无定义"。但 x 趋近 1 时会怎样？

x = 1 处函数是"断的"（空心圆），但从两边逼近，f(x) 都无限趋近 2。所以极限存在：limx→1 f(x) = 2。

极限的正式表述（通俗版）The Definition
limx→a f(x) = L   读作："当 x 无限趋近 a 时，f(x) 无限趋近 L"

关键点：不要求 x 真的等于 a。函数在 a 处甚至可以没有定义（如上例）。极限只关心"逼近"的行为，不关心"到达"。

19 世纪柯西和魏尔斯特拉斯用 ε-δ 语言严格化了"无限趋近"——大意是：你给我任意小的误差容忍 ε，我都能找到一个范围 δ，让 x 落在 a 的 δ 范围内时，f(x) 就落在 L 的 ε 范围内。这就是微积分"无懈可击"的根基。
连续性：没有"跳跃"Continuity

如果一个函数在某点的极限值 等于 它的实际值，就说函数在该点连续。直观上就是"一笔画下来不断开"。

  • 连续 = limx→a f(x) = f(a) —— 极限值 = 实际值
  • 不连续 = 有跳跃、断点或空心 —— 极限不存在或不等于实际值
  • 微积分研究的函数默认是连续的（或分段连续），因为不连续的点上导数无意义
补章：微积分的"信任危机"与严格化
贝克莱的攻击："已死量的幽灵"The Crisis

牛顿的微积分虽然结果总是对的，但逻辑上有漏洞。他让增量 o "消失"--但 o 到底是不是零？如果是零，除以 o 就是除以零（无意义）；如果不是零，凭什么让它消失？

1734 年，爱尔兰主教贝克莱发表了著名的攻击："这些流数是什么？是消失增量的速度。那这些消失的增量又是什么？它们既不是有限量，也不是无穷小量，也不是零。难道不能叫它们'已死量的幽灵'吗？"

这不是抬杠。贝克莱指出的是一个真实的逻辑漏洞：微积分在推导过程中先假设增量不为零（用来做除法），后又让它等于零（用来消去项）。这种"既是零又不是零"的矛盾，让微积分在诞生后 150 年里都处于"好用但说不清"的尴尬状态。
柯西：用极限重建微积分Cauchy · 1821

柯西的关键贡献：不再依赖"无穷小量"这个模糊概念，而是用极限重新定义一切。

  • 极限的严格定义（1821）：当变量逐步逼近一个值，最终与它相差任意小，这个值就是极限
  • 连续性：用极限重新定义 -- limx->a f(x) = f(a)
  • 导数：明确定义为差商的极限：f'(x) = lim f(x+h)-f(x)h
  • 积分：定义为黎曼和的极限（不再只是"无穷多个矩形"的直觉）
  • 级数收敛：建立了判别无穷级数是否收敛的准则

柯西把微积分从"依赖无穷小量"变成了"完全基于极限"。无穷小量不再是基础概念，而只是"一个趋于零的变量"的简称。

魏尔斯特拉斯：ε-δ 语言Weierstrass · 1850s

柯西的定义虽然前进了一大步，但"任意小""逐步逼近"这些词仍然依赖直觉。魏尔斯特拉斯把它们变成了纯逻辑的陈述：

limx->a f(x) = L 的含义：

对任意 ε > 0，存在 δ > 0，
使得当 0 < |x - a| < δ 时，
就有 |f(x) - L| < ε。
  • ε = 你能容忍的误差（要多小有多小）
  • δ = 我给你的逼近范围（保证误差在 ε 内）
  • 整个过程不涉及"无穷小"，只用有限的不等式

魏尔斯特拉斯还发现了一个颠覆直觉的函数：处处连续但处处不可导。这说明"直觉"是不可靠的--只有严格的逻辑才能保证正确性。

极限是微积分的地基。导数是"比值的极限"，积分是"求和的极限"。理解了极限，后面的所有概念都只是它的不同应用。

导数的本质：瞬时变化率The Intuition

你在高速公路上开车，仪表盘显示 120 km/h。这个数字是什么意思？它不是"过去一小时的平均速度"，也不是"从起点到现在的平均速度"——它是此刻这一瞬间的速度。

但"一瞬间"的时间跨度是零，距离变化也是零，0/0 有意义吗？这就是微积分要解决的问题。

从平均速度到瞬时速度Average → Instantaneous

思路很简单：取一个很小的时间间隔 Δt，算平均速度 = ΔsΔt。然后让 Δt 越来越小——取极限。

瞬时速度 = limΔt→0   ΔsΔt

即   v(t) = limΔt→0 s(t+Δt) - s(t)Δt

这个表达式，就是导数的定义。把 s(t) 换成任意函数 f(x)，就得到了一般形式：

f'(x) = limΔx→0 f(x+Δx) - f(x)Δx
可视化：割线变切线

图中的彩色虚线是"割线"——连接 P 点和附近 Q 点的线。Q 越靠近 P，割线斜率越接近 2。当 Q 无限逼近 P 时，割线就变成了切线，切线的斜率就是导数。

导数 = 切线斜率 = 瞬时变化率。这三个说法是同一件事的三种表达。

用定义求导太慢了。前辈数学家已经帮我们把常见函数的导数和运算法则总结好了——记住这些，95% 的求导就能秒杀。

更关键的是——后面会看到，深度学习的反向传播，本质上就是对整个神经网络做链式法则。这条法则不只是考试题，它是 AI 的引擎。

这些公式是怎么来的？--用定义推导From First Principles

上面的公式表不是凭空猜的。每个公式都可以从导数的定义 f'(x) = lim f(x+h)-f(x)h 一步步推导出来。看两个最重要的例子。

示例 1：幂法则 d/dx[xⁿ] = n·xⁿ⁻¹
用定义：f'(x) = limh→0 (x+h)ⁿ - xⁿh

第一步：用二项式定理展开 (x+h)ⁿ
  (x+h)ⁿ = xⁿ + n·xⁿ⁻¹·h + n(n-1)2·xⁿ⁻²·h² + ... + hⁿ

第二步：减去 xⁿ
  (x+h)ⁿ - xⁿ = n·xⁿ⁻¹·h + n(n-1)2·xⁿ⁻²·h² + ... + hⁿ

第三步：除以 h
  = n·xⁿ⁻¹ + n(n-1)2·xⁿ⁻²·h + ... + hⁿ⁻¹

第四步：取极限 h→0，所有含 h 的项消失
  f'(x) = n·xⁿ⁻¹ ✓

每一项含有 h 的因子，在 h->0 时全部归零，只留下第一项 n·xⁿ⁻¹。这就是幂法则的来历--不是记忆口诀，而是二项式展开 + 取极限的自然结果。

示例 2：正弦函数 d/dx[sin(x)] = cos(x)
用定义：f'(x) = limh→0 sin(x+h) - sin(x)h

第一步：用和角公式展开 sin(x+h)
  sin(x+h) = sin(x)cos(h) + cos(x)sin(h)

第二步：代入并整理
  sin(x+h) - sin(x) = sin(x)[cos(h) - 1] + cos(x)·sin(h)

第三步：除以 h
  = sin(x) · cos(h) - 1h + cos(x) · sin(h)h

第四步：取极限 h→0，用两个经典极限：
  • limh→0 sin(h)h = 1   (弧长与弦长之比 → 1)
  • limh→0 cos(h) - 1h = 0   (余弦变化比 h 慢)

第五步：代入
  f'(x) = sin(x)·0 + cos(x)·1 = cos(x) ✓

这个推导用到了两个"经典极限"--它们本身可以用几何直觉（单位圆上弧长与弦长的关系）来理解。sin(h)h → 1 的几何含义：当角度 h 很小时，弧长 ≈ 弦长，比值趋近于 1。

导数的导数：高阶导数Higher Derivatives

导数本身也是函数，可以再求导。二阶导数 f''(x) 就是"变化率的变化率"——它告诉你变化本身在加速还是减速。

物理直觉：位移 → 速度 → 加速度Physics Intuition
位移 s(t)求导 ↓ 速度 v(t) = s'(t)再求导 ↓ 加速度 a(t) = v'(t) = s''(t)

你踩油门，车加速——位移在变（有速度），速度也在变（有加速度）。加速度就是位移的二阶导数。牛顿第二定律 F = ma 本质上就是 F = m·s''(t)。

一阶导数：增减f'(x)
  • f'(x) > 0 → 函数递增（上坡）
  • f'(x) < 0 → 函数递减（下坡）
  • f'(x) = 0 → 极值点（山顶或谷底）
二阶导数：凹凸f''(x)
  • f''(x) > 0 → 凹向上（碗口朝上，加速增长）
  • f''(x) < 0 → 凸向下（碗口朝下，减速增长）
  • f''(x) = 0 → 拐点（凹凸切换处）
一阶导数告诉你"往哪走"，二阶导数告诉你"弯向哪"。这就像开车——方向盘是二阶导数，油门是一阶导数，而你的位置就是函数本身。
积分的本质：无限累积The Intuition

如果导数是"切片"——把整体切成瞬间看变化率；那积分就是"拼接"——把无数个瞬间的微小量累积成一个整体。

最直观的例子：你知道每时刻的速度 v(t)，怎么算总共走了多远？把每个瞬间走的微小距离 v(t)·dt 加起来——这就是积分。

从矩形逼近到精确面积Riemann Sums

曲线下方的面积怎么算？古代人用"穷竭法"，现代人用黎曼和：把面积切成无数个细矩形，矩形面积之和逼近真实面积。

∫ab f(x) dx = limΔx→0 Σ f(xi)·Δx

无数个细矩形的面积之和，当矩形无限窄时，就是曲线下方的精确面积

导数是极限的比值，积分是极限的求和。一个在"切"，一个在"拼"——但它们其实是同一枚硬币的两面。怎么证明？下一章告诉你。

这些公式是怎么来的？--从求导倒推From Differentiation

积分的所有公式都能从求导公式倒推出来--因为积分就是"谁的导数是它"这个问题。看两个最重要的例子。

示例 1：幂法则 ∫xⁿ dx = xⁿ⁺¹/(n+1) + C
思路：求"谁的导数是 xⁿ"。先猜一个候选，再验证。

第一步：猜候选函数 xⁿ⁺¹（次方加一）

第二步：对它求导
  ddx[xⁿ⁺¹] = (n+1)·xⁿ   (幂法则)

第三步：多了系数 (n+1)，除以它修正
  ddx[ xⁿ⁺¹n+1 ] = xⁿ   ✓

第四步：验证结果
  ∫xⁿ dx = xⁿ⁺¹n+1 + C   (C 是任意常数，因为常数求导为零)

这就是积分公式表的来历--不是硬背，而是"猜一个、求导、修正系数"的试错法。每次看到一个积分，问自己：什么函数求导会变成它？

示例 2：换元法 ∫ 2x·cos(x²) dx
观察：2x 恰好是 x² 的导数——这是链式法则的"指纹"。

第一步：设 u = x²，则 dudx = 2x

第二步：替换
  ∫ 2x·cos(x²) dx = ∫ cos(u) · du

第三步：对 u 积分
  = sin(u) + C

第四步：把 u 换回 x
  = sin(x²) + C ✓

验证：ddx[sin(x²)] = cos(x²)·2x ✓ (链式法则，回代验证)

看出套路了吗？第 4b 章求导示例里的 sin(x²) 求导结果是 2x·cos(x²)，这里就是它的逆运算。一组求导 + 积分互为镜像：d/dx[sin(x²)] = 2x·cos(x²) ⟷ ∫2x·cos(x²)dx = sin(x²)。这正是微积分基本定理的日常使用方式。

定积分 vs 不定积分Definite vs Indefinite
不定积分Indefinite
∫f(x)dx = F(x) + C
  • 结果是一个函数族（差一个常数 C）
  • 问的是："谁的导数是 f(x)？"
  • 本质：反求导
定积分Definite
∫ab f(x)dx = F(b) - F(a)
  • 结果是一个数值（面积、总量）
  • 问的是："从 a 到 b 累积了多少？"
  • 本质：黎曼和的极限
定积分的直觉Intuition

定积分最直观的意义就是面积。但它不限于面积——任何"连续变化量的累积"都可以用定积分计算：

速度 → 位移
∫v(t)dt = 总路程。速度曲线下的面积 = 走了多远
力 → 功
∫F(x)dx = 总功。力曲线下的面积 = 做了多少功
功率 → 能量
∫P(t)dt = 总能量。功率曲线下的面积 = 消耗多少能量
密度 → 质量
∫ρ(x)dx = 总质量。密度曲线下的面积 = 物体总重
定积分 = "变化率的累积"。只要你知道某个量的变化率，积分就能告诉你总量——这就是积分的万能之处。
微积分基本定理：两座桥，一个定理The Fundamental Theorem

这是微积分最深刻的结论，没有之一。它说的是：求导和积分互为逆运算。切线和面积——这两个困扰人类两千年的难题，原来是同一枚硬币的两面。

可视化：面积函数的导数 = 原函数
第一部分：面积函数的导数FTC Part 1
如果 F(x) = ∫ax f(t)dt
那么 F'(x) = f(x)

通俗版：面积函数的变化率，就是原函数本身。面积增长快慢，取决于该点 f(x) 有多高——f(x) 高，面积涨得快；f(x) = 0，面积不涨。

第二部分：用反求导算定积分FTC Part 2
如果 F'(x) = f(x)，则
∫ab f(x)dx = F(b) - F(a)

通俗版：要算面积，不用真的去画矩形。只要找到 f(x) 的反导数 F(x)，把两端点值一减，面积就出来了。这让积分从"无限求和"变成了"查表 + 减法"。

为什么这是个"奇迹"Why It's a Miracle

求导和积分，一个来自"求切线"，一个来自"求面积"。它们看起来毫无关系——一个在"切"，一个在"拼"。但基本定理告诉你：它们互为逆运算。

这意味着：你不需要为了每个积分去算无穷多个矩形的和。只要会求导（反过来就会积分），就能算面积。这就是为什么微积分能成为一门实用学科——没有基本定理，微积分只是哲学；有了它，微积分成了工具。
积分 = 无限求和黎曼和的极限，计算量无穷大
›
积分 = 反求导 + 代入找到 F(x)，算 F(b)-F(a)，几步搞定
牛顿发明微积分，就是为了算运动Why Newton Invented Calculus

高中物理背过一堆公式：v = v₀ + at、s = v₀t + ½at²……这些公式怎么来的？它们不是猜的，是用微积分从 F = ma 一步步推导出来的。一旦理解了这个推导，你就再也不用死记硬背了。

第一步：定义运动的语言Step 1
位置 s(t)Position
物体在时刻 t 的位置——最基本的状态量
速度 v(t) = s'(t)Velocity
位置的一阶导数——位置变化有多快
加速度 a(t) = v'(t) = s''(t)Acceleration
速度的导数 = 位置的二阶导数——速度变化有多快
第二步：牛顿第二定律 = 微分方程Step 2
F = m·a = m·s''(t)

力 = 质量 × 加速度 = 质量 × 位置的二阶导数

这就是牛顿第二定律的微积分形式。它本质上是一个微分方程：已知力 F，求位置 s(t)。

第三步：自由落体——完整推导Step 3 · Free Fall

物体自由下落，唯一的力是重力 F = -mg（负号表示向下）。代入 F = ma：

①   m·s''(t) = -mg   →   s''(t) = -g   (加速度恒定 = -g)

②   两边积分：s'(t) = ∫(-g)dt = -gt + C₁   (速度)
    代入初始条件 t=0 时 v=v₀：  v(t) = v₀ - gt   ✓

③   再积分：s(t) = ∫(v₀ - gt)dt = v₀t - ½gt² + C₂
    代入初始条件 t=0 时 s=s₀：  s(t) = s₀ + v₀t - ½gt²   ✓
看到了吗？v = v₀ - gt 和 s = s₀ + v₀t - ½gt²——高中物理让你背的公式，就是积分两次的结果。知道了推导过程，你理解的是公式背后的逻辑，而不是死记的符号。
微分方程：微积分的"方程"Differential Equations

含导数的方程叫微分方程。物理定律几乎都是用微分方程写的——因为物理关心的不是"状态本身"，而是"状态怎么变"。看四个经典例子：

自由落体
s''(t) = -g  →  解：s = s₀ + v₀t - ½gt²
上面刚刚算过：积分两次得到抛物线
冷却定律
dTdt = -k(T - T₀)
"温度下降速度 ∝ 温差"——解是指数衰减，热水变凉的数学解释
弹簧振动
x''(t) = -ω²x
"加速度 ∝ 位移"——解是正弦波 sin(ωt)，弹簧、钟摆、振荡电路全用它
种群增长
dPdt = rP
"增长 ∝ 种群本身"——解是指数增长，复利、人口模型、细菌繁殖同理
四种方程，四种人生：二次积分得抛物线，一阶微分得指数，二阶振荡得正弦。微分方程就是"用导数描述规则，用积分还原轨迹"。
微分方程的最高成就：从引力推出开普勒定律Kepler from Gravity

这是牛顿微积分最辉煌的一役：从万有引力 F = GMmr² 出发，纯粹用微积分推出行星的椭圆轨道。完整推导链：

  1. 写运动方程：牛顿第二定律 F = m·s''(t)，代入引力：s''(t) = -GMr² · êr
  2. 极坐标分解：把加速度分解为径向和切向，得到两个微分方程（r 和 θ 各自满足）
  3. 面积积分：切向方程两边乘 r 后积分，得到 r²·dθdt = h（常数）——角动量守恒
  4. 解读：r²·dθdt = 常数 意味着"单位时间扫过的面积相等"——这就是开普勒第二定律（等面积定律）✓
  5. 径向方程：做变量替换 u = 1/r，把径向方程化为关于 u 的简谐振子方程
  6. 求解并还原：解出 r(θ) = p1 + e·cosθ——圆锥曲线方程；离心率 e < 1 时就是椭圆，开普勒第一定律 ✓
从一条假设（万有引力）出发，微积分推出了两条经验定律。这就是微积分的威力：用数学把"为什么"变成"必然"。
可视化：位移 → 速度 → 加速度

反过来也成立：积分是"求导的逆"。从加速度积分得到速度，再积分得到位移。微积分让你在"力"和"运动"之间自由穿梭——这就是物理世界的翻译器。

通信的基石：傅里叶变换Fourier Transform

你手机里发出的声音、WiFi 传的信号、5G 基站的数据——全部建立在同一个积分公式上。这个公式就是傅里叶变换，而它的核心，就是一个积分。

核心思想：任何信号都是正弦波的叠加The Big Idea

傅里叶的发现极其大胆：任何连续信号——不管多复杂——都可以拆解成一组不同频率正弦波的叠加。就像任何颜色都是红绿蓝的混合，任何信号都是不同频率"纯音"的混合。

F(ω) = ∫-∞+∞ f(t)·e-iωt dt

f(t) = 时域信号（你说话的波形）
F(ω) = 频域信号（分解出的频率成分）
这个积分，把"时间"翻译成了"频率"
时域 f(t)→ 傅里叶变换 ∫→ 频域 F(ω)→ 滤波 / 调制 / 压缩
可视化：方波 = 正弦波的叠加

三个正弦波加在一起，已经开始像方波了。如果继续加 sin(7ωt)、sin(9ωt)……无限项求和——就能得到完美的方波。这就是傅里叶级数：复杂信号 = 无限个正弦波的积分叠加。

关键原理：正交性——正弦波怎么被"筛"出来Orthogonality

为什么一定能拆成正弦波？因为不同频率的正弦波是正交的——它们在"内积"（乘积的积分）意义下互不干扰：

∫0T sin(mωt)·sin(nωt) dt = 0   (m ≠ n)

自己和自己：  ∫0T sin²(nωt) dt = T2   (m = n)

几何直觉：在向量世界里，"垂直"的两个向量点积为零，所以互不干扰。正弦波在"积分空间"里也是一样的——不同频率 = 互相垂直，同频率 = 只有自己。就像对着一群人大喊，只有喊到和自己同频的人，对方才听得最清楚。

复杂信号 f(t)→ 乘 sin(nωt)→ 求一个周期的积分→ 其他频率全部"抵消"（正交积分=0）→ 只留下第 n 个频率的系数
傅里叶系数 an = 2T·∫0T f(t)·sin(nωt)dt，就是一个"频率筛子"：乘上去、积一下，其他频率全部归零，只筛出 n 倍频的强度。没有正交性，这个"筛子"根本不成立。
通信领域的应用Applications
4G / 5G 调制
OFDM 正交频分复用——把数据分到几百个子载波上，每个都是正弦波。全靠傅里叶变换在时域和频域间切换。
音频 / 图像压缩
MP3 和 JPEG 都先用傅里叶变换把信号转到频域，然后丢掉人耳/人眼不敏感的频率——体积骤减，听感/观感几乎不变。
滤波器设计
噪声往往是高频成分。傅里叶变换→去掉高频→反变换回时域，信号就干净了。所有降噪都基于此。
雷达 / 成像
回波信号的频率偏移告诉你目标速度，时间延迟告诉你距离——全靠对信号做频域分析。
每次你用手机打电话、连 WiFi、刷视频，背后都有无数次傅里叶积分在跑。通信工程的整个大厦，建在这个积分上。
AI 的引擎：梯度下降Gradient Descent

训练 AI 模型——不管是 ChatGPT 还是图像识别——本质上就是在做一件事：调整参数，让"错误"最小化。怎么知道往哪个方向调？靠导数。这就是梯度下降。

核心思想：蒙眼下山The Intuition

想象你蒙着眼站在山坡上，要走到谷底（误差最小处）。你脚下用脚试一下——哪个方向最陡，就往那个方向走一步。不断重复，最终走到谷底。"最陡的方向"就是梯度，"走一步"就是参数更新。

数学表达：每一步都是导数The Math

一个神经网络有 n 个参数（权重）w₁, w₂, ..., wₙ。损失函数 L 衡量"当前有多错"。梯度是 L 对每个参数的偏导数组成的向量：

∇L = ( ∂L∂w₁ , ∂L∂w₂ , ... , ∂L∂wₙ )

更新规则（每一步）：
wᵢ ← wᵢ - η · ∂L∂wᵢ   (对所有 i)

η = 学习率（步长大小）
∂L∂wᵢ = 偏导数（参数 wᵢ 方向上的"陡度"）
减号 = 逆梯度方向走（下山，不是上山）

这里每个 ∂L∂wᵢ 就是一个偏导数——本质和你在课本上学的 dy/dx 完全一样，只是扩展到多变量。没有导数，AI 就不知道该往哪走。

反向传播 = 链式法则Backpropagation = Chain Rule

神经网络有几十上百层，怎么算最前面参数的梯度？用链式法则——从输出层开始，一层层往回传，每一层乘一个导数。

前向传播：算预测值→ 计算损失 L→ 反向传播：链式法则算 ∂L∂wᵢ→ 梯度下降更新 wᵢ
反向传播的本质，就是对整个网络应用链式法则。你在第四章学的 [f(g(x))]' = f'(g)·g'(x)，就是深度学习训练的数学内核——只是扩展到了几百层、几十亿个参数。
很多参数怎么办：偏导数Partial Derivatives

损失函数 L 依赖成百上千亿个参数 w₁, w₂, ..., wₙ。问"L 对 w₁ 的变化有多敏感"时，把其他参数全部当常数，只对 w₁ 求导——这就是偏导数 ∂L∂w₁。

梯度 ∇L = ( ∂L∂w₁ , ∂L∂w₂ , ... , ∂L∂wₙ )

∇ 读作 "nabla"（梯度符号）——一个向量，指向 L 上升最快的方向；反向就是下降最快
偏导数 = "只动一个旋钮，看错误怎么变"。梯度下降就是同时转动所有旋钮，每个旋钮转多少、往哪转，由各自的偏导数决定。
具体算一遍：两层网络的链式法则A Concrete Example

假设一个最小网络：输入 x，第一层乘 w₁，过激活函数 σ，再乘 w₂，输出 ŷ = w₂·σ(w₁x)。训练目标是让预测 ŷ 接近真实值 y，损失取 L = ½(ŷ - y)²。求 L 对 w₁ 的偏导：

链式法则逐层回传：

第一步：损失对输出求导
  ∂L∂ŷ = (ŷ - y)   (平方损失求导)

第二步：输出对 w₂ 求导
  ∂ŷ∂w₂ = σ(w₁x)   (乘的系数就是偏导)

第三步：输出对 w₁ 求导（穿过激活函数）
  ∂ŷ∂w₁ = w₂ · σ'(w₁x) · x   (内层再乘 x)

第四步：乘起来（链式法则）
  ∂L∂w₁ = (ŷ - y) · w₂ · σ'(w₁x) · x   ✓

第五步：更新参数
  w₁ ← w₁ - η · ∂L∂w₁   (η = 学习率)
注意误差的"回流"轨迹：损失 ŷ-y 先传到输出，再乘上路径上每个环节的导数往回传——一层层相乘，正是"反向传播"名字的由来。训练一亿参数的模型，就是这条链做了几十亿次。
梯度下降的变体Variants
  • SGD：随机梯度下降，每次用少量样本
  • Adam：加动量+自适应步长，最常用
  • 学习率调度：先大后小，先快走后精调
为什么 AI 离不开微积分Why Calculus
  • 训练 = 最小化损失 → 需要导数指方向
  • 多层网络 → 需要链式法则传梯度
  • 没有微积分 → AI 无法学习

AI 的"智能"，来自亿万次微积分运算。每一次参数更新，都是一个导数；每一次训练迭代，都是梯度下降的一步。微积分不是 AI 的附属品，而是 AI 的引擎。

给"学过但忘了"的你：一条重新学习的路线A Learning Path

你有基础，只是生疏了。不需要从零开始啃教材——按照下面这条路线，每步配合可视化理解，大约两到三周就能重建完整的微积分直觉。

七步重建微积分直觉
  1. 重建直觉（2-3天）——先不看公式，回到物理直觉。理解导数="瞬时变化率"、积分="累积量"。用开车的例子：速度表=导数，里程表读数差=定积分。
  2. 过一遍极限（2天）——不用纠结 ε-δ 证明，理解"无限趋近但不到达"即可。重点理解 0/0 型极限和连续性的概念。
  3. 掌握求导法则（3-4天）——背熟基本公式表（幂、指数、对数、三角），重点练链式法则。会求导=会做70%的微积分题。
  4. 理解积分（3天）——黎曼和的直觉 + 基本积分公式。掌握换元法和分部积分这两个核心技巧。
  5. 打通基本定理（1-2天）——理解"求导和积分互逆"这个核心。这是把微积分从两个独立话题统一成一个体系的关键。
  6. 挑一个应用深入（3-5天）——从物理运动（牛顿定律）、信号处理（傅里叶）、机器学习（梯度下降）中选一个你感兴趣的，亲手推导一遍。
  7. 扩展视野（持续）——多元微积分（偏导数、梯度）、微分方程、数值方法……根据需要逐步扩展。
